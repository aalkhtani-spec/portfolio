# Oracle Forms 6i Portfolio

Bilingual Arabic/English portfolio for Anas Al-Qahtani.

## GitHub Pages
1. Create a new public GitHub repository.
2. Upload `index.html` and the `assets` folder to the repository root.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide the public URL.

No build process or dependencies are required.
